# release Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/) and this project adheres to [Semantic Versioning](http://semver.org/).

## 2.0.0 - 2026-11-11
### Changed
- Require Craft CMS 4 and PHP 8.0.2 or newer.
- Register user permissions and the control panel section with Craft 4 APIs.
- Send the release webhook from a protected controller action using Craft's HTTP client.
- Keep the webhook secret out of the control panel page and report request failures.
